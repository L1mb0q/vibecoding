Модуль 1: Введение в Python

Python — это язык программирования высокого уровня. Его главные принципы — простота и читаемость. Код на Python часто выглядит как обычный английский текст.

Первая программа: Традиционно обучение начинают с вывода фразы "Hello, World!" на экран.

В Python для этого используется функция print().

Модуль 2: Типы данных и переменные

Переменные — это именованные ячейки памяти. В Python не нужно явно указывать тип данных, он определяется автоматически (динамическая типизация).

Основные типы:

  • int — целые числа (age = 25)
  • float — числа с точкой (price = 99.99)
  • str — строки (name = "Иван")
  • bool — булевы значения (is_active = True)

Тест модуля 2

2. Какой оператор используется для склеивания (конкатенации) строк?

3. Как проверить тип переменной?

Модуль 3: Условия и циклы

Программы должны уметь принимать решения. Для этого используются условные операторы if, elif, else.

Для повторения действий используются циклы. Самый популярный — for.

Тест модуля 3

2. Какой цикл подойдет, если мы заранее не знаем, сколько раз нужно повториться?

3. Что выведет код: print(bool(0))?

Модуль 4: Функции

Функция — это переиспользуемый блок кода. Она объявляется с помощью ключевого слова def. Функции могут принимать аргументы и возвращать результат через return.

Тест модуля 4

2. Что делает оператор return?

3. Какое значение вернет функция, если в ней нет оператора return?
